🚀 How to Run the Programs

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open the terminal.
4. Compile the required C++ file.

Example:

g++ -std=c++14 practicals/01_fundamentals.cpp -o practical

5. Run the program:

Windows:

.\practical.exe

Linux/macOS:

./practical

Note: Compile and run one practical file at a time because each program has its own "main()" function.
